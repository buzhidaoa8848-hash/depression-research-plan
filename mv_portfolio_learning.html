1 核心概念

1.1 资产与收益率

来源：ch7-2 第3页

  • 投入 x0x_0x0​ 资金，到期收回 x1x_1x1​
  • 总收益率（Total Return）：R=x1/x0R = x_1 / x_0R=x1​/x0​
  • 收益率（Return Rate）：r=(x1−x0)/x0=R−1r = (x_1 - x_0) / x_0 = R - 1r=(x1​−x0​)/x0​=R−1
  • 利润：p=x1−x0=r⋅x0p = x_1 - x_0 = r \cdot x_0p=x1​−x0​=r⋅x0​

1.2 做空 (Short Selling)

来源：ch7-2 第4页

  • 先借入资产卖出（x0<0x_0 < 0x0​<0），后低价买回归还
  • 收益率公式不变：r=(x1−x0)/x0r = (x_1 - x_0) / x_0r=(x1​−x0​)/x0​
  • 若 x1<x0x_1 < x_0x1​<x0​（低价买回）⇒r>0\Rightarrow r > 0⇒r>0

1.3 随机收益率

来源：ch7-2 第8-9页

  • 收益率是随机变量，不是确定值
  • 期望回报：E[r]=rˉ\mathbb{E}[r] = \bar rE[r]=rˉ（平均预期）
  • 方差：Var⁡[r]=σ2\operatorname{Var}[r] = \sigma^2Var[r]=σ2（风险度量）
  • 例如掷骰子：E[r]=1/6\mathbb{E}[r] = 1/6E[r]=1/6, Var⁡[r]=3.81\operatorname{Var}[r] = 3.81Var[r]=3.81

4 算法流程

输入：rˉ\bar rrˉ（期望回报）, Σ\SigmaΣ（协方差矩阵）, rdr_drd​（目标回报）
输出：w∗w^*w∗（最优权重）, σp2\sigma_p^2σp2​（最小方差）
  1. 准备数据：收集 nnn 个资产的 rˉ\bar rrˉ 和 Σ\SigmaΣ（通常用历史数据估计）
  2. 计算 CCC 参数：Crr,Cer,CeeC_{rr}, C_{er}, C_{ee}Crr​,Cer​,Cee​
  3. 解 λ,μ\lambda, \muλ,μ：通过 2×22 \times 22×2 矩阵求逆
  4. 计算最优权重：w∗=Σ−1(λrˉ+μe)w^* = \Sigma^{-1}(\lambda \bar r + \mu e)w∗=Σ−1(λrˉ+μe)
  5. 计算最小方差：σp2=w∗′Σw∗\sigma_p^2 = w^{*\prime} \Sigma w^*σp2​=w∗′Σw∗
  6. 画有效前沿：改变 rdr_drd​ 重复步骤3-5
现实问题：rˉ\bar rrˉ 和 Σ\SigmaΣ 未知，用历史数据估计存在误差。最优权重对输入高度敏感，称为"估计误差最大化"。改进方向包括 shrinkage 估计和 Black-Litterman 模型。

题4（概念）

为什么加入无风险资产后有效前沿从曲线变成直线？

无风险资产方差为0，组合风险完全由风险资产承担：
σp=(1−α)σ风险\sigma_p = (1-\alpha) \sigma_{\text{风险}}σp​=(1−α)σ风险​

这是线性关系。在所有可行直线中，与有效前沿相切的那条为 CML。
