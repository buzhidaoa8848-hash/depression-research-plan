# 医学小样本学习方法综述

## 一、问题定义

医学AI面临的核心矛盾：**临床数据获取成本高、标注贵、样本量小**，而深度学习天然需要大数据。

DAIC-WOZ/E-DAIC 总计 ~460 sessions，属于典型的小样本医学场景。

## 二、方法体系

### 2.1 预训练 + 微调 (Pretrain + Fine-tune)

**核心思想**：在大规模通用/领域数据上预训练，在目标任务上微调少量参数。

**医学领域的成功案例**：
- wav2vec2.0 在 LibriSpeech (960h) 预训练 → DAIC-WOZ 微调（论文1）
- MentalBERT 在 Reddit 精神健康语料 (1.2B tokens) 预训练 → 抑郁文本分类（论文3）
- ClinicalBERT 在 MIMIC-III (2M notes) 预训练 → 临床任务

**对你的大创的适用性**：
| 方法 | 你的应用 | 建议 |
|:----|:---------|:-----|
| wav2vec2 frozen feature | DAIC-WOZ 语音特征 | ✅ 已经在 M1 中使用 |
| MentalBERT frozen embedding | 文本特征 | ✅ 已经在 M1 中使用 |
| Whisper + LoRA 微调 | 语音特征 | 🔥 推荐尝试（第六部分已有分析） |
| OpenFace + ViT 预训练 | 面部特征 | ⚠️ 数据太小，效果有限 |

**关键原则**：小样本下 <strong>冻结特征提取器</strong> 是安全策略，全参数微调几乎必然过拟合。

### 2.2 自监督学习 (Self-supervised Learning)

**核心思想**：利用无标注数据自身结构设计预训练任务（对比学习、掩码重建等）。

**医学领域的应用**：
- SimCLR / MoCo 在医学影像上的对比学习预训练
- HuBERT 在语音上的掩码预测预训练
- MAE (Masked Autoencoder) 在视频上的重建预训练

**对你的大创的适用性**：
- HuBERT 做语音特征：✅ 已有成功先例
- 对比学习做模态对齐：⚠️ 值得尝试，但需要设计合适的数据增强策略

### 2.3 多实例学习 (MIL)

**核心思想**：将 session 拆分为 utterance，用注意力池化聚合，天然适合小样本（每个 session 贡献多个实例）。

**对你的大创的适用性**：<strong>⭐⭐⭐⭐⭐ 最适合</strong>
- 已在 M1 中使用
- 每个 session ~200 utterances → 460 sessions ~ 92,000 实例
- 实例级的多样性弥补了 session 级样本不足

### 2.4 弱监督 (Weak Supervision)

**核心思想**：用规则/启发式/外部知识生成噪声标签，扩大训练数据。

**对你的大创的可能性**：
- 用 LLM 从文本自动抽取 PHQ-9 症状维度 → 生成弱标注
- 利用外部知识库（DSM-5）生成症状-标签映射规则

### 2.5 数据增强 (Data Augmentation)

**医学场景的有效增强策略**：

| 模态 | 增强方法 | 可行性 |
|:----|:---------|:------|
| 文本 | EDA (同义词替换/回译) | ✅ 简单 |
| 文本 | LLM 生成 paraphrase | ✅ 效果好但贵 |
| 语音 | Speed perturbation / noise addition | ✅ 简单 |
| 语音 | SpecAugment (频谱掩码) | ✅ 标准做法 |
| 面部 | Random cropping / color jitter | ✅ 简单 |
| 面部 | Mixup / CutMix | ⚠️ 需验证 |

### 2.6 校准与不确定性估计

**对你大创的价值**：⭐⭐⭐⭐⭐ 虽然是"小样本"问题，但临床场景最重视可靠性。

| 方法 | 说明 | 复杂度 |
|:----|:-----|:------|
| Temperature Scaling | 单参数后处理校准 | ⭐ 极低 |
| Platt Scaling | 逻辑回归校准 | ⭐ 低 |
| Monte Carlo Dropout | 多次dropout推理解释不确定性 | ⭐⭐ 中 |
| Deep Ensemble | 多个模型集成 | ⭐⭐⭐ 高 |
| Bootstrap CI | 重采样估计置信区间 | ⭐⭐ 中 |
