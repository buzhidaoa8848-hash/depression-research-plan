# 每周追踪记录 V2

> 基于 2026 年 5 月更新。每周追踪：新论文、新数据集、新方法、可复现实验。

## 追踪模板

每周复制以下格式填写：

```
## 第X周 (开始日期 ~ 结束日期)

### 本周新论文
| 标题 | 年份 | 是否看完 | 关键发现 | 对我有用？ |
|:-----|:----:|:--------:|:---------|:----------:|
| | | | | |

### 本周新数据集
| 名称 | 状态 | 获取进展 | 备注 |
|:----|:----|:--------|:-----|

### 本周实验进展
| 编号 | 状态 | 关键结果 | 问题 |
|:----:|:----:|:---------|:-----|
| | | | |

### 下周计划
- [ ] 
- [ ] 

### 需要老师确认
- 

### 需要队友操作
- 

### 笔记/思考
```

## 追踪字段说明

| 字段 | 说明 |
|:----|:-----|
| 新论文 | 发现的对本模块有用的新文献 |
| 新数据集 | 新发现的可申请数据集 |
| 实验进展 | 实验编号+状态+关键数字 |
| 需要老师确认 | 下一步需要导师把关的方向 |
| 需要队友操作 | 需要队员申请数据/跑实验 |
