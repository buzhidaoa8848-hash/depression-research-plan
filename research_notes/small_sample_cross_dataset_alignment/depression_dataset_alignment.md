## 二、各数据集详细分析

### 2.1 DAIC-WOZ (基准数据集)
- 样本：189 sessions（47 抑郁 / 142 非抑郁）
- 模态：音频 44.1kHz + 视频 30fps + 转录文本
- 标签：PHQ-8 (0-24) + binary (≥10=抑郁)
- 特点：最广泛使用的抑郁检测学术基准，适合做主训练集
- 对齐角色：源域 (source domain)

### 2.2 E-DAIC (主要扩展)
- 样本：275 sessions
- 模态：音频 + 转录文本（部分有视频）
- 标签：PHQ-8 + binary
- 与DAIC-WOZ关系：同一个实验室的后续扩展，采集协议一致
- 对齐角色：源域扩展 / 跨域验证目标域
- 对齐难度：⭐（容易，同协议同语言）

### 2.3 MODMA (跨语言关键数据集)
- 样本：三种子集（语音52+101+EEG50）
- 模态：语音 + EEG（无视频、无完整文本转录）
- 标签：PHQ-9 + binary
- 语言：中文
- 对齐难点：
  - 语言不同 → 文本LLM需要跨语言迁移
  - 仅音频，缺视频/面部
  - PHQ-9 vs PHQ-8（一个症状区别）
- 对齐角色：外部验证 / 跨语言测试
- 对齐难度：⭐⭐⭐⭐（难，语言+模态缺失）

### 2.4 AVEC 系列
- 每年主题不同：2013抑郁+情感，2014抑郁+情感，2016 DAIC-WOZ发布
- AVEC 2016 的测试集可用来做外部验证
- 与DAIC-WOZ同源，对齐较容易

### 2.5 CLPsych / eRisk
- 社交媒体文本，非访谈数据
- 标签有风险等级、支持/求助意图等
- 可用来验证文本模态的泛化性
- 但对齐难度大（任务定义不同）

## 四、对齐难点总结

| 难点 | 说明 | 可能的解决方案 |
|:----|:-----|:--------------|
| 语言差异 (英→中) | 文本特征不一致 | 跨语言embedding (LaBSE, XLM-R) |
| 模态缺失 | 有的没视频、有的没音频 | 用可用模态训练，缺失模态留空 |
| 标签差异 (PHQ-8 vs PHQ-9) | 一个症状的差别 | 统一为binary标签 |
| 标签分布差异 | 不同数据集抑郁比例不同 | 重采样/加权 |
| 采集协议差异 | 访谈vs问卷vs社交媒体 | 只对齐可对齐的部分 |
| 样本量不平衡 | DAIC-WOZ 189 vs CMDC ~1000 | 加权采样 |
