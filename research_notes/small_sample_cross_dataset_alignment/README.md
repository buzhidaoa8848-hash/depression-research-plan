# 小样本医学多模态学习与跨数据集对齐/泛化

> 大创项目：DAIC-WOZ / E-DAIC 多模态抑郁风险筛查
> 研究模块：小样本学习 + 跨数据集泛化

## 模块定位

本项目主模型为 MIL + Attention Pooling + LLM 症状特征抽取（M0→M3）。
本模块作为**论文发表后的延伸研究方向**，解决 DAIC-WOZ/E-DAIC 小样本场景下的核心瓶颈：
- 样本量有限（~460 sessions）导致模型泛化性存疑
- 多数据集间模态对齐困难（不同语言、采集协议、标签体系）
- 缺乏跨数据集验证的标准评估框架

## 核心问题

1. **数据少**：DAIC-WOZ 仅 189 sessions，E-DAIC 275 sessions，总计 ~460
2. **模态多**：文本+音频+视频，每个模态都需要单独的处理 pipeline
3. **域偏移**：不同数据集语言不同（英/中）、采集协议不同、标签定义不同
4. **评估难**：缺乏大规模外部验证集，难以评估真实泛化能力

### 6. 哪些方向是坑，不要现在碰？

| 方向 | 为什么是坑 |
|:-----|:----------|
| 端到端多模态 LLM (LLaVA等) | 无GPU/API预算，460样本必过拟合 |
| GAN 面部数据增强 | 复杂，失真，临床不可靠，审稿人不认 |
| EEG+音频+视频强行融合 | MODMA 的 EEG 和 DAIC 的视频完全不兼容 |
| 全参数微调大模型 | 无GPU，小样本必过拟合 |
| 纯 prompt zero-shot LLM | 不稳定，无实验保障，审稿人不认 |
| 社交媒体+访谈数据合并 | 域差异太大，强行合并反而降低性能 |

### 7. 如果只能做一个核心创新，应该是什么？

> **症状引导的多模态可解释融合框架 + 跨数据集症状稳定性验证**

核心卖点：
1. LLM 从访谈文本中按 PHQ-9 维度抽取结构化症状特征
2. 症状特征与 wav2vec2/MentalBERT/OpenFace 传统特征通过 MIL attention 融合
3. 在 DAIC-WOZ 和 E-DAIC 上做跨数据集验证，证明症状维度的跨域稳定性
4. 结果包含：AUC + 校准 + Bootstrap CI + 多种子 + 消融 + 注意力可视化

**这个创新点同时满足**：
- ✅ 方法新颖（目前无人做症状维度的跨域对齐）
- ✅ 可解释（能说清"为什么判断抑郁"）
- ✅ 临床价值（症状级输出对医生有用）
- ✅ 可实现（本科大创算力足够）
- ✅ 答辩展示效果好（症状雷达图+attention热力图）
