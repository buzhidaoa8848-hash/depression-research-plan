### 1.3 CMDC 标签冲突分析（重点）

**需要您亲自核实。我目前看到的信息如下：**

| 来源 | 标签说法 | 可信度 | 判断 |
|:-----|:---------|:------:|:-----|
| LREC 2024 原始论文 | 访谈内容对齐 PHQ-9 维度，有 PHQ-8+二分类 | ⭐⭐⭐ | 最权威，但需看完整论文 |
| GitHub README (部分) | HAMD-17 评分 | ⭐⭐ | 可能混淆了其他评估 |
| 中文博客/介绍文 | PHQ-9 中文版 | ⭐⭐ | 常见说法 |

**我的判断（需核实）**：
- CMDC 很可能同时有 **PHQ-8/PHQ-9 自评** + **HAMD-17 他评** 两类标签
- 访谈内容按 PHQ-9 维度设计（与 DAIC-WOZ 按 PHQ-8 同理）
- **最可能对齐策略**：使用 PHQ-8 分数（如完整论文确认有PHQ-8则直接对齐）

## 四、跨数据集实验设计

```
实验A: 同域验证 (低难度)
  DAIC-WOZ train → DAIC-WOZ test (5-fold CV)
  E-DAIC train → E-DAIC test (5-fold CV)

实验B: 跨域验证（同语言，中难度）
  DAIC-WOZ train → E-DAIC test
  E-DAIC train → DAIC-WOZ test

实验C: 跨域验证（跨语言，高难度）
  DAIC-WOZ+E-DAIC train → CMDC test (if audio/text)
  DAIC-WOZ+E-DAIC train → MODMA test (audio only)

实验D: Pooled 训练
  DAIC-WOZ+E-DAIC → DAIC-WOZ+E-DAIC CV
  DAIC-WOZ+E-DAIC+CMDC(audio) → cross-dataset eval
```

## 五、数据集风险提示

| 数据集 | 风险 | 应对 |
|:------|:-----|:-----|
| CMDC | 申请可能被拒、标签待核实 | 先确认标签再申请 |
| MODMA | EEG+音频，视频缺失，跨模态困难 | 只用音频部分 |
| EATD | SDS标签，不能和PHQ-8直接合并 | 分开训练，分别评估 |
| eRisk/CLPsych | 社交媒体与访谈差异巨大 | 仅用于相关工作，不合并训练 |
